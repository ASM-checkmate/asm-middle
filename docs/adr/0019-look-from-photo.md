# ADR-0019: 사진은 겉모습 옵션 여섯 개로만 옮긴다 — 모델이 고르고, 캐릭터는 우리가 그린다

*   날짜: 2026-09-10
*   상태: 채택됨 (실험실 단계. 온보딩 화면에 붙이는 것은 다음)

## 배경

캐릭터는 하나(모모)였다. 오너의 방향: 사람 사진을 넣으면 그 사람을 닮은 캐릭터가 나와야 한다. 먼저 공개된 인물 사진으로
시험하고 진행한다. 캐릭터는 SVG 조각(character/)으로 그려지고 포즈 10개·탈것 6개·방 안 96px·뒷모습까지 한 세트라,
이미지 생성으로 대체하면 그 전부를 잃는다.

## 결정

**사진에서 비전 모델이 고르는 것은 옵션 여섯 개뿐이다. 그 값으로 우리 캐릭터를 다시 그린다. 신원은 묻지도 답하지도 않는다.**

1.  **겉모습(`Look`) 여섯 칸.** 피부 5단계(light·fair·tan·brown·dark), 머리색 7(black·dark-brown·brown·blond·red·gray·white),
    머리 모양 7(bowl·short·buzz·bob·long·curly·bald), 안경 3(none·round·square), 수염 4(none·stubble·mustache·full),
    상의 색 7(coral·sun·mint·sky·night·paper·leaf — 앱 토큰 색). `sim/types.ts`에 상수와 `isLook` 검증.
2.  **백엔드 `POST /api/character/look`.** 사진(긴 변 512px JPEG dataURL, 본문 상한 1.5 MB)을 비전 모델에 보내 JSON 스키마로
    여섯 칸과 `seen`(겉모습 한 문장)을 받는다. 그림 읽기(ADR-0007)와 같은 구조(Prompt·Schema·Parser·Validator). 허용값이 아니면
    칸마다 기본값(모모)으로 떨어진다. 프롬프트는 "누구인지는 답하지 않는다"를 못 박는다.
3.  **색은 CSS 변수, 모양은 Head가 그린다.** 피부·머리·상의 색은 캐릭터 svg 뿌리의 `--ch-skin`·`--ch-hair`·`--ch-top`으로 얹는다 —
    `<use>`로 그리는 얼굴 심볼(defs.tsx)과 탈것의 손·발까지 한 번에 물든다. 머리 모양·안경·수염은 `Head`가 `look`을 보고 그린다.
    친구 얼굴은 고정색이라 같은 svg에 함께 타도 내 색을 안 받는다.
4.  **저장은 `memory.look`.** 없으면 지금의 모모 그대로다(모든 기본값이 모모). `OwnerLookContext`로 앱 루트에서 내려보내
    `Character`(variant me)·`CharacterDefs`·`Rider`가 읽는다. 친구의 겉모습은 아직 없다 — `Friend`에 같은 `look`을 붙이면 된다.
5.  **실험실에서 시작한다.** `?lab=character`의 "겉모습" 칸: 사진 고르기 → 모델이 고른 여섯 칸 → 손으로 고치기 → "내 캐릭터로 저장".
    QA는 `&look=<base64 JSON>`. 온보딩·프로필 화면에 붙이는 것은 이 결정의 범위 밖이다.

## 근거

*   **재현 가능하고 검증 가능하다.** 결과가 여섯 칸의 열거값이라 스키마 하나로 검증되고, 같은 값이면 어디서나 같은 캐릭터다.
    ADR-0018(장소 레시피)과 같은 원칙 — 모델은 고르고 코드가 그린다.
*   **스타일이 안 흔들린다.** 이미지 생성은 포즈·탈것·뒷모습·96px 축소를 다 새로 만들어야 하고 팔레트도 못 맞춘다.
*   **측정(2026-09-10, 공개 인물 사진 1장, 512px):** qwen3.8:27b(good) 5.5초 — 피부 dark·머리 black·short·정장 night, 맞음.
    qwen3.5:9b·gemma4:12b — 피부 light·머리 gray로 틀림. 그래서 이 호출은 `good`이 기본이고, 작은 모델은 실험실에서만 고른다.
*   **신원을 다루지 않는다.** 사진은 서버에 남기지 않고(응답만), 프롬프트는 겉모습만 묻는다. 유명인 사진은 시험용이고 저작권이
    없는 공개 사진(공식 초상, 퍼블릭 도메인)만 쓴다.

## 영향

*   `Memory.look`(선택) 한 칸. 저장본 검증은 `loadMemory`의 `isLook`. 서버 문서는 통째 저장이라 계약 변경 없음(CONTRACT의 새 엔드포인트만).
*   `C.skin`·`C.hair`가 hex에서 `var()`로 바뀌었다 — 캔버스 등 SVG 밖에서 이 값을 쓰면 안 된다(지금은 없다).
*   머리 모양 7개 중 short·buzz·curly·long·bald는 새 그림이다. 뒷모습도 각각 있다.
*   다음: 온보딩(이름 짓기 옆에 사진), 친구 겉모습, 안경·수염 외 액세서리(모자 등)는 필요할 때.
