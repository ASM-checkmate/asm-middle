# 2편 라이브 시연 — 공시생의 하루 (`?scenario=gongsi`)

영상(`demo-gongsi.json`)과 같은 하루를 **손으로** 보여 준다.

**이 브랜치(`demo-live`)는 백엔드도 Gemini 키도 없이 돈다.** 사진을 찍으면 서버 대신 미리 만들어 둔 생성 컷(`public/demo/*.png`, `dev/scenario.ts`의 `DEMO_SHOTS`)이
5초 "현상 중" 뒤에 "생성됨"으로 나온다 — 자리마다 한 장(스타벅스 창가·코노 마이크 앞·포차 앞 테이블·드론쇼 앞). 같은 자리에서 또 찍으면 같은 그림이니 **한 자리에 한 장만** 찍는다.
(`camera` 브랜치는 진짜 생성 — 백엔드 + `GEMINI_API_KEY`.)

## 1. 켜기 (시연 5분 전)

```sh
git switch demo-live
cd frontend && npm run dev            # http://localhost:5173 — 이것만 있으면 된다
```

## 2. 들어가기

브라우저(폰 크기로 — 크롬 기기 툴바 390×844 권장)에서:

```
http://localhost:5173/?scenario=gongsi&reset=1&day=2026-09-15&at=9:35&dev=1
```

- 로그인 화면이 뜨면 **오프라인으로 시작**을 누른다(백엔드가 없으니 아이디 목록도 안 뜬다).
- `reset=1`이라 새로고침할 때마다 09:35 스타벅스에서 다시 시작한다 — 실수하면 새로고침.
- `dev=1`: 왼쪽 아래 `x30` 알약이 개발 패널이다(시계 배속·시각 점프). 시연 중엔 알약을 눌러 **x1**로 두고, 장면을 넘길 때만 점프한다.
- `day=2026-09-15`는 마찰 굴림을 고정한다 — 바꾸면 밤에 코노 대신 딴 데로 샐 수 있다.

## 3. 순서 (영상과 같다)

| 장면 | 하는 것 | 보이는 것 |
| --- | --- | --- |
| 09:35 스타벅스 | 그냥 보여 준다 | 창가 자리, 에듀윌 노트북·기본서, 장소 태그의 `AD` |
| 시간표 | 오른쪽 위 📅 → 원판에서 **밤** → 카드 **코인노래방에서 스트레스 풀기** → **이걸로 정할래** → 닫기 | "캐릭터가 대신 골랐어요"(집에서 넷플릭스) → 사용자가 바꿈 → "정해졌어요 · 20:00 출발" |
| 사진 | 캐릭터가 창가 자리에 있을 때 **📷 창가 자리** 칩 → **찍기** → **다 찍었어** | 필름 1칸이 "현상 중"으로 흔들리다 5초 뒤 **생성됨**(미리 만든 컷) |
| 친구 | 개발 패널 **10:30** 점프 | 옆 테이블 현이 "안녕!", 태그 옆 "새 친구 · 현이" |
| 장소 지도 | 장소 태그 옆 📍 → 지도 시트 → 닫기 | 스타벅스 부산대점 핀, 네이버·구글 링크 |
| 이동 | 개발 패널 **19:45** 점프 → x30으로 올리고 기다리거나 **20 밤** 점프 | 20:00 집에서 나와 걸어서 코인노래방(지도 위 실제 경로, 5분) |
| 코노 | 도착하면 x1. 코인 기계 존 → 마이크 존 → **📷 마이크 앞** → 찍기 | 핸드마이크 들고 노래, 음표·점수 큐, 생성 사진 |
| 귀가·잠 | **23:45** 점프 → 걸어서 집 → 자정 넘으면 잠 화면 | SNS(왼쪽 위 💬) 친구 탭에 현이 |

- 사진 생성은 활동이 **끝나기 전**(now < endAt)에 셔터를 눌러야 앨범에 들어간다 — 점프하기 전에 찍는다.
- 점프하면 건너뛴 활동은 자동 정산되고 앨범(오른쪽 위 📖)에 "안 찍길래 내가 한 장 찍었어"로 남는다.

## 4. 막힐 때

- 사진 칸이 "합성만"으로 끝난다 → 그 자리엔 미리 만든 컷이 없다(`DEMO_SHOTS`에 없는 배경) 또는 시나리오 URL(`?scenario=`)이 아니다. 콘솔에 `shotgen(demo):` 줄이 이유를 말한다.
- 밤에 코노가 아닌 데로 간다 → `day=2026-09-15`가 빠졌다.
- 처음부터 → URL 새로고침(`reset=1`).
