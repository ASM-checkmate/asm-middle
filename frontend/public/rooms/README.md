# 방

`<방>/room.json` — 방 랩(`?lab=room`)이 읽는다. 방은 **그림 한 장**(`back`)이고 사람은 늘 그 위에 그려진다.

## 왜 소품을 안 떼나
예전엔 침대·서랍장을 낱개로 떼어 바닥 접점으로 앞뒤를 정했다 (가구 뒤로 걸어가면 가려지게). 그런데 그러면 침대 쪽으로
걸어가다 **사람이 가구 뒤로 사라진다**. 어차피 가구 뒤를 걸어 다닐 일이 없으니, 가구는 배경에 두고 **걸을 수 있는 바닥
(`walk` 다각형)** 밖으로 못 나가게 막는다. 그러면 가려질 일이 없고, 소품 자르기·앞뒤 순서가 통째로 필요 없어진다.

## 트리거존
`zones` 의 칸에 들어서면 그 자리의 동작(`scene`)이 걸린다. 동작 그림은 **'그 물건 + 사람'이 함께 그려진 방 전체 그림**
몇 장이라, 조각낼 것 없이 배경째 갈아 끼우고 사람 그림은 안 그린다 — 이불 위/아래 같은 가림이 그림 안에 이미 들어 있다.

장면은 `enter`(들어가는 길)와 `frames`(그 자리에서 도는 칸)로 나뉜다. 서 있다가 곧바로 누우면 순간이동처럼 보이니
자기는 **걸터앉기 → 이불 위에 눕기 → 이불 덮고 잠** 을 거치고, 나올 땐 그 길을 거꾸로 되짚는다.

배경이 바뀔 땐 **새 그림만 위에서 덮으며 나타난다**. 두 장을 같이 반투명으로 겹치면 사이로 흰 바탕이 비쳐 한 번
번쩍인다 (양쪽 다 0.5면 흰색이 25 % 섞인다).

## 만드는 법
```bash
python3 scripts/room-build.py anime      # art/gen 의 그림 → public/rooms/anime
python3 scripts/room-build.py bedroom
```
바닥(`walk`)·존(`zones`)·집 자리(`home`)는 `scripts/room-build.py` 의 `ROOMS` 에 방 좌표(390×600)로 적는다.
방 랩에서 "디버그" 를 켜면 바닥 다각형과 존이 보이니 그걸 보며 맞춘다.

## 새 방을 더할 때
그림은 **모델이 그린 방**이어야 편집본의 구도가 유지된다 (외부 그림을 "침대만 빼" 로 고치면 구도를 다시 잡아 버린다).
필요한 그림은 방 전체 1장 + 동작마다 2~3장. 소품 편집본(-empty·-no-bed…)은 이제 안 쓴다.
