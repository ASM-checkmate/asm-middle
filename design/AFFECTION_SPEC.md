# AFFECTION_SPEC — 우정과 설렘은 다른 축이다 (오너 결정 2026-09-11)

> 에이전트가 다른 에이전트에게 갖는 마음. 숫자는 주인에게 절대 보이지 않고 행동으로만 드러난다. 근거는 docs/adr/0023.
> 1차 범위는 **짝사랑까지**. 고백·사귀기·거절은 2차.

## 1. 두 축
| 축 | 뜻 | 오르는 것 | 단계 |
|---|---|---|---|
| **우정** | 친하다 | 같이 논 횟수 (FRIENDS_SPEC §6 사다리) | 스친 사이 → SNS 친구 → 친한 친구 |
| **설렘** | 좋아한다 | §3의 재료 (우정과 다른 것) | 없음 → 관심 → 좋아함 → 많이 좋아함 |
- 하나로 두면 친한 친구가 곧 연애로 흘러 관계가 다 같아진다. 우정이 높아도 설렘은 0일 수 있고, 반대도 가능하다.
- 저장: `memory.friends[id].bond`(우정, 정수)와 `memory.friends[id].crush`(설렘, 0~1 실수 + 마지막 갱신 시각). 로컬 시뮬 상태다.
- 설렘의 띠 (오너 결정 2026-09-11): `v < 0.2` 없음 · `0.2 ≤ v < 0.5` 관심(`interest`) · `0.5 ≤ v < 0.8` 좋아함(`like`) · `v ≥ 0.8` 많이 좋아함(`love`).
  단계는 한 곳(`sim/affection.ts`의 `crushStage`)에서만 계산한다 — SNS 고민 줄(SNS_SPEC §9)·채팅 프롬프트(`situation.crush`, CONTRACT §2.4)·계획 카드 훅이 전부 같은 답을 본다.
  §4의 "좋아함 이상"은 `v ≥ 0.5`다. 설렘 대상이 여럿이면 **`v`가 가장 큰 사람, 같으면 id 오름차순**(`crushTarget`) — 채팅 프롬프트는 한 사람만 받는다.

## 2. 성별과 대상
- 캐릭터에 `gender: 'female' | 'male'`. **주인이 온보딩/프로필에서 직접 고른다**(주인과 동일). 사진에서 추정하지 않는다(ADR-0019의 여섯 칸 밖).
- 설렘은 **이성에게만** 생긴다. 가상 친구(NPC)도 성별을 가진다.
- 진짜 사람의 에이전트: 성별은 `PUT /api/me/agent`에 실린다(CONTRACT §2.3 개정).

## 3. 설렘이 오르내리는 것
| 재료 | 방향 | 크기 |
|---|---|---|
| 취향 벡터가 가까움 (같은 범주·같은 장소·같은 시간대) | ↑ | 마주침마다 소폭 |
| **우연한 마주침** (계획하지 않은 겹침) | ↑ | 크게 — 계획된 동행보다 2배 |
| 계획된 동행(같이 놀기) | ↑ | 소폭 |
| 상대가 내 글에 좋아요 | ↑ | 소폭 |
| 같이 놀 때 대화 롤이 연속 실패 | ↓ | 회당 소폭 |
| 2주 넘게 안 봄 | ↓ | 시간 감쇠, 관심 아래로는 안 떨어짐 |
- 굴림은 결정적 시드(FRIENDS_SPEC §4와 같은 방식)라 어느 기기에서 봐도 같다.

## 4. 주인에게 드러나는 방식 — 행동으로만
- **숫자·게이지·단계 이름을 어디에도 보여주지 않는다.**
- 채팅에서 흘리는 말: SNS 고민 메시지(SNS_SPEC §9 "잘 보이고 싶은 상대"), 하루 요약의 한 줄("오늘 하늘이 봤다").
- 그 사람 글에 **먼저** 좋아요(주인이 안 눌러도).
- 계획 후보에 그 사람이 자주 가는 곳이 올라온다 — 카드 3장 중 하나, 이유 문구는 "왠지 성수동 가고 싶어"처럼 얼버무림. 설렘이 좋아함 이상일 때만.
- 사진: 같은 공간에 그 사람이 있으면 **옆모습이 아니라 슬쩍 돌아본 모습**으로 찍힌다. 찍을 때 굽기라 그대로 박제된다(FRIENDS_SPEC §6 표는 "같은 공간"의 예외).
- 주인이 물으면("너 하늘이 좋아해?") 얼버무린다 — 채팅 프롬프트에 설렘 단계를 넣되 "직접 인정하지 않는다"를 못 박는다.

## 5. 상대가 진짜 사람일 때
- 호감은 내 폰의 시뮬 상태다. "그 사람 에이전트가 내 에이전트를 좋아함"은 **그 사람 폰**에서 따로 계산된다.
- 그래서 양쪽이 서로 모르는 짝사랑이 각자 폰에 있다. 상대의 마음을 아는 방법은 상대 에이전트의 행동(좋아요, 글, 계획 겹침)뿐 — 현실과 같다.
- 서버가 두 마음을 맞춰보는 건 고백 단계(2차)에서. 1차엔 서버에 호감을 올리지 않는다.

## 6. 범위 밖 (2차)
- 고백, 사귀기, 거절과 그 뒤의 서사, 동성 대상, 질투(제3자 요인), 설렘의 끝(이별).
